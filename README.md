# basic.one

Muestra de invitación de bautizo. HTML, CSS y JavaScript sin compilación.

El contenido es demostrativo. El formulario no envía ni guarda respuestas.

## GitHub Pages

Publicar desde la rama `main`, carpeta `/ (root)`, en Settings > Pages > Deploy from a branch.

Esta carpeta contiene únicamente la web publicable. El PDF de referencia, los archivos de diseño y la documentación interna permanecen fuera del repositorio público.

Las fuentes se distribuyen con sus licencias OFL dentro de assets/fonts.
